# Deadline Radar website

The public landing page for Deadline Radar, served by GitHub Pages at https://deadline-radar.github.io/DeadlineRadar/.

## Making a change

1. Edit `index.html` in this folder and save.
2. In GitHub Desktop, pick this repository, write a short summary, click **Commit to main**, then **Push origin**.
3. The live page updates about a minute later.

Not affiliated with Instructure or Canvas.
